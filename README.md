# Codec64

Browser-only encoding and conversion tools. Input never leaves the browser.

## Tools

- **Base64** — encode and decode Base64 and Base64url.
- **URL** — encode and decode URL components.
- **Query Params** — convert query strings and JSON.
- **JWT** — decode JWT headers and payloads without signature verification.
- **Python → JSON** — convert Python literals and JSON in either direction.
- **Timestamp** — convert Z time, Unix seconds, and Unix milliseconds.
- **Tailwind colors** — browse Tailwind CSS colors and match hex values to the closest token.

## Local development

```sh
cd ui
pnpm install --frozen-lockfile
pnpm run dev
```

Development binds to `0.0.0.0:$UI_INT_PORT`; `$UI_EXT_PORT` controls host exposure. Playwright preview uses
`$UI_TEST_INT_PORT`. The canonical runtime values live in `.devcontainer/.env`, which Make and the Astro and Playwright
configs read. Change that file to update ports. Copy `.devcontainer/.env.example` as a reference when setting up a
workspace; it documents defaults and is not loaded by the app. `UI_EXT_PORT` and `API_EXT_PORT` select host ports;
`UI_INT_PORT`, `UI_TEST_INT_PORT`, `API_INT_PORT`, and `API_TEST_INT_PORT` select container ports. API ports are
placeholders for a future service. `ASTRO_TELEMETRY_DISABLED=1` disables Astro telemetry.

## Build and test

Run current workflow from repository root:

```sh
make build
make lint
make test
make test-e2e
```

`make build` creates production output in `./docs/`. `make lint` runs Prettier, type checks, ESLint, and Semgrep.
Unit and browser tests stop on first failure.
`make lighthouse-ci` audits the built output (gates accessibility, SEO, best practices; performance is advisory);
`make lighthouse` audits the deployed site.

When using a preinstalled Chromium outside Playwright's expected browser build, set
`PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH` to its executable. Set `PLAYWRIGHT_VIDEO=off` when the matching FFmpeg
build is unavailable. For this devcontainer:

```sh
PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH=/ms-playwright/chromium/chrome-linux64/chrome PLAYWRIGHT_VIDEO=off make test-e2e
```

Conversions run on browser main thread and target text inputs up to 1 MB. Larger-input support should move codec work into Web Workers.

`./docs/` is generated by Astro. Do not edit generated files.
